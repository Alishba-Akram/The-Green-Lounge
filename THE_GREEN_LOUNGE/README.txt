THE GREEN LOUNGE — HTML WEBSITE

Files:
- index.html
- about.html
- menu.html
- contact.html
- gallery.html

How to run:
1. Extract this folder.
2. Open the folder in VS Code.
3. Open index.html in your browser, or use the Live Server extension.
4. Use the top navigation to move between pages.

Design:
- Soft off-white and sage green palette inspired by the supplied reference.
- Forest green headings and buttons.
- Botanical / restaurant imagery loaded from Unsplash URLs.
- CSS is written inline in each HTML element as requested.

Notes:
- Internet is required for the remote images and embedded map.
- Contact form is a demo using mailto; it does not store messages on a server.
- Menu prices and contact details are sample content. Replace them with verified business details.
- For production, connect the contact form to a backend and use the restaurant's real address and phone number.
